# Página pessoal — GitHub Pages

## Objetivo

Página HTML simples que exibe a saudação `Olá!!`, adequada como exercício inicial de publicação de páginas estáticas.

## Tecnologia e estrutura

- HTML5.
- `index.html`: página principal.

## Visualização

Abra `index.html` em um navegador. O endereço esperado para publicação, caso o GitHub Pages esteja habilitado, é https://sandra-tavares.github.io/.

## Pendências

A meta tag viewport contém `width=Olá` em vez de `width=device-width`. O atributo de idioma está definido como `en`, embora o conteúdo esteja em português. Recomenda-se revisar esses atributos. A publicação e a renderização não foram testadas; o HTML foi mantido sem alterações.
